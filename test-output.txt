Integration Tests:
------------------
Integration tests require a Postgres instance. The test suite includes:
- tests/api.test.mjs (11 acceptance tests from v0.1.0)
- tests/schema.test.mjs (new DB_SCHEMA test)

To run integration tests:
  export DATABASE_URL="postgres://postgres:postgres@localhost:5432/threadbus"
  npm test

Expected behavior verified in code:
- DB_SCHEMA creates schema if not exists
- All migrations run in the specified schema
- Pool configured with search_path option
- Server logs which DATABASE_URL source was used
- Server logs DB_SCHEMA when set
